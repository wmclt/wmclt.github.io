# Hallo

Dit is een poging om een _poepsimpele_ webpagina te maken om gebruikers gemakkelijk hun *de*s en *het*s te laten uitoefenen.

# Tips/Vuistregels
- verkleinwoord (bv.: meisje, huisje, oventje) -> altijd "het"
- woord is dier -> altijd "de" **behalve** konijn, paard, schaap en varken
- woord beschrijft een "mens" (bv: rechter, schaatser, agent, vriendin) -> altijd "de"
- woord eindigt op `-ing`, `-tie` of `-heid` -> 99% van de tijd "de" (uitzonderingen: "het ding", "het ondercheid" al bevat dat woord niet echt het "-heid" achtervoegsel)
- ...

Zie ook: https://www.vlaanderen.be/team-taaladvies/taaladviezen/woordgebruik/de-of-het
